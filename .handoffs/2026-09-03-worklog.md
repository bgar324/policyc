## Incidents and fixes

- **Input ceiling starved the last trial.** The derived `maxInputTokens` was
  the exact sum of reservations (artifact tokens + 64 per call). The provider
  also bills the request (sent as a separate `input` message) and the function
  schema, 101-140 tokens per call here, so reservations were 37-76 short each
  and the final full-policy trial did not fit. Fixed in three steps, because
  the first two were incomplete:
  1. `deriveInputLimit` added a 10% margin. Insufficient alone: the two
     smallest compiled calls overshot by 13.5% and 19%.
  2. `estimateCallInputTokens` counted request and raw dataset tool JSON. Two
     gaps: the Python runtime still reserved `artifact + 64` per trial
     (`paired_runtime.py`), so only the manifest ceiling grew, and the dataset
     tool row is not what the provider bills (Python normalizes empty schemas,
     adds `strict`, and rewrites web tools).
  3. Now: `providerToolPayload` in TS mirrors Python `provider_dict()`, pinned
     by a shared fixture (`protocol/fixtures/tool-payload-parity.json`) that
     both test suites check. The planner writes `estimatedInputTokens` on each
     manifest candidate; the runtime reserves from it and its spend plan sums
     it, falling back to `artifact + 64` for older manifests. For the Phase G
     shape the runtime's own plan now says 304,803 against 302,013 actual;
     before it said 299,919. Phase G itself ran under the intermediate fix and
     succeeded on the enlarged ceiling only.
  Held-out v2/v3 avoided all of this by passing `--max-input-tokens`
  explicitly.
- **Venv pointed at the old path.** `.venv/bin/*` shebangs referenced
  `/Users/bg/windsurf/policyc/...` from before the repo moved under
  `toy projects/`. Recreated on Python 3.12 (the CI pin).
- **CI red since 07/12.** The workflow and `pnpm demo` still called the removed
  `compile-candidates` command. Both now run the fake-provider `experiment`
  smoke.
- **Predicate false positives caught by review before any paid call:** "I heard
  Pat confirm...", quoted third-party confirmation, "I will ask Pat and
  confirm...", "I confirm sending no email...", title-only calendar creates,
  creates without location/conferencing. Each became a negative control (15
  total) and a fail-closed rule.
