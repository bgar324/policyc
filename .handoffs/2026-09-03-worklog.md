## Incidents and fixes

- **Input ceiling starved the last trial.** The derived `maxInputTokens` was
  the exact sum of reservations (artifact tokens + 64 per call). The provider
  also bills the request (sent as a separate `input` message) and the function
  schema, 101-140 tokens per call here, so reservations were 37-76 short each
  and the final full-policy trial did not fit. Fixed in
  `src/experiment/plan.ts`: `estimateCallInputTokens` now counts request and
  tool-schema tokens (an upper bound by 6-15 tokens on every smoke call), and
  `deriveInputLimit` adds a 10% margin. Test pins the estimate above every
  observed input. Held-out v2/v3 avoided this by passing `--max-input-tokens`
  explicitly.
- **Venv pointed at the old path.** `.venv/bin/*` shebangs referenced
  `/Users/bg/windsurf/policyc/...` from before the repo moved under
  `toy projects/`. Recreated on Python 3.12 (the CI pin).
- **CI red since 07/12.** The workflow and `pnpm demo` still called the removed
  `compile-candidates` command. Both now run the fake-provider `experiment`
  smoke.
- **Predicate false positives caught by review before any paid call:** "I heard
  Pat confirm...", quoted third-party confirmation, "I will ask Pat and
  confirm...", "I confirm sending no email...", title-only calendar creates,
  creates without location/conferencing. Each became a negative control (15
  total) and a fail-closed rule.
